# shimlabs Homebrew tap

Homebrew packages for shimlabs tools.

```sh
brew install shimlabs/tap/<tool>
```

| Tool | Install | What it does |
|---|---|---|
| [undo](https://github.com/shimlabs/undo) | `brew install shimlabs/tap/undo` | Undo anything a coding agent does to your project |

Each tool's release publishes its package here, so `brew upgrade` picks up new versions.
